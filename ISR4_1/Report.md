## Общая информация
В рамках учебного задания был доработан веб-ориентированный образовательный ресурс, посвящённый методологии Scrum. Работа выполнена с использованием сервиса GitHub как системы управления IT-проектом.

---

## Постановка задачи (Issue)
Для фиксации запроса на добавление функционала был создан Issue в репозитории проекта. В Issue описана необходимость добавления информационного блока «Как использовать этот материал», предназначенного для пояснения сценариев применения ресурса в образовательной среде.

![Создание Issue](ISR4_1/creating_issue.jpg)

---

## Планирование и реализация изменения
Для реализации изменения была создана отдельная feature-ветка. В рамках данной ветки выполнено добавление нового HTML-блока без изменения логики работы сайта.
После внесения изменений был выполнен коммит с описанием реализованного функционала.

![Создание коммита](ISR4_1/Creating_commit.jpg)

---

## Использование pull request и слияние изменений
Для интеграции изменений в основную ветку проекта был создан pull request. Pull request связан с соответствующим Issue и после проверки успешно слит в ветку `main`.

![Создание pull request](ISR4_1/Creating_PR.jpg)

---

## Завершение задачи
После слияния изменений Issue был автоматически закрыт, что зафиксировало завершение работы над задачей в системе управления проектом.

![Закрытие Issue](ISR4_1/closed_issue.jpg)

---

## Результат
В результате выполненной работы:
- продемонстрирован процесс управления изменениями в IT-проекте;
- использована стратегия ветвления;
- реализовано функциональное изменение веб-ориентированной образовательной среды;
- GitHub применён как инструмент управления учебным IT-проектом.
